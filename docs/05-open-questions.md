# 05. Открытые вопросы

Требуют установленной игры (`Assembly-CSharp.dll`, dll PUN/Photon Voice) и разбора через ILSpy.
На рабочей станции, где создавалась база знаний, игры пока нет.

| # | Вопрос | Зачем |
|---|---|---|
| 1 | Где и с какими `AppSettings` игра вызывает подключение (ConnectUsingSettings / ConnectToRegion)? | Точка для патча |
| 2 | Используется ли `AuthValues` с `CustomAuthenticationType.Steam`? | Нужно ли отключать Steam-авторизацию для своего сервера |
| 3 | Как Steam-лобби связано с комнатой Photon (имя комнаты в lobby data)? | Инвайты (этап 4) |
| 4 | Отдельный ли клиент у Photon Voice (свой AppId и NameServer)? | Голос на своём сервере |
| 5 | Есть ли у игры свой выбор региона и пинг-тест, которые сломаются без облака? | UX и ошибки |
| 6 | Работает ли голос на LuxonServer «из коробки»? | Этап 0, возможно PR в upstream |
| 7 | Какая версия PUN и протокола (Protocol18)? | Совместимость сервера |
