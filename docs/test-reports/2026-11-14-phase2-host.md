# 2026-11-14: Phase 2, Host mode on one PC

## Environment

- Game: R.E.P.O. v0.5.1 (Steam build 26407089), BepInEx 5.4.23.6
- SemiLink 0.2.0 with bundled LuxonServer v1.5
- One PC with an Ethernet adapter and Radmin VPN installed. **Not a multiplayer test.**

## Results

| Check | Result |
|---|---|
| Panel appears in the main menu, F8 / click expands it | ✅ |
| Switch to Host: bundled server starts and reports "running" | ✅ about 1 s |
| Address hints | ✅ Radmin VPN adapter labelled "VPN (Radmin VPN)", Ethernet labelled "Local network"; Copy works |
| Private game in Host mode | ✅ Region page shows a single region (Europe); lobby opens with 7 ms ping |
| Mode toolbar locked in the lobby | ✅ "Leave the lobby to change the mode." |
| LAN announcement | ✅ A separate UDP listener on port 47777 received `SEMILINK|1|<Steam name>` |
| Join mode: LAN list | ✅ Test announcements appear; protocol 2 shown as "(different SemiLink version)" with Use disabled; Use with protocol 1 fills the address |
| Host → Join: server stops | ✅ |
| Host mode persisted: server starts on the next game launch | ✅ |
| Game closed normally: server stops | ✅ |
| Game force-killed: server process terminated by Windows (job object) | ✅ no orphan process |

## Not verified

- A second player joining (LAN or VPN), voice audio between players.
- Windows Firewall prompts for `luxon_server.exe` (incoming server) and `REPO.exe` (LAN discovery listener)
  on a PC where they were never allowed before.
- Port already in use error path (code exists, not exercised).

## Notes

- The LAN list is keyed by sender IP: one host per PC.
- The server starts as soon as Host is selected (including on game launch when Host was the last mode), so
  it is ready before the player clicks *Private game*.
